# Yihua Xu — Professional Research Website

This repository publishes Yihua Xu's professional research website at
<https://yvonnexu442.github.io/>.

The site is dependency-free static HTML, CSS, and vanilla JavaScript. GitHub
Pages serves the `main` branch from the repository root.

## Local preview

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000/>.

## Public-content boundary

Only public-safe website assets belong in this repository. Do not commit
reviewer evidence, private résumés, unpublished manuscripts, client materials,
credentials, local screenshots, or internal planning documents.

A custom domain is intentionally not configured in Version 1.0.
